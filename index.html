Markdown 서식 제거

Markdown을 붙여넣으면 서식을 제거한 평문으로 변환합니다.

무료 · 가입 없음 · 입력 내용 저장 없음

결과

변환된 내용이 여기에 표시됩니다.
변환 방식
  • 제목·강조: 제목, 굵게, 기울임, 취소선 기호를 제거합니다.
  • 목록: -와 중첩 들여쓰기를 유지하고, *와 + 목록은 -로 바꿉니다.
  • 체크박스: [x]와 [ ]를 그대로 유지합니다.
  • 링크·이미지: 설명 (URL) 형식으로 표시합니다.
  • 코드: 코드 내용을 유지하고, 지정된 언어는 [swift]처럼 표시합니다.
  • 인용문: > 기호를 제거하고 내용을 유지합니다.
  • 표: 미리보기에서는 테이블로 표시하고, 평문 복사에서는 탭으로 구분합니다.
